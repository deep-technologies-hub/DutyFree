# Duty Free Manager — Backoffice

Application de pilotage : tableau de bord temps réel, reporting, ventes, produits, catégories, taux de capture, fidélité, utilisateurs, exports, configuration, **inscription** (`/inscription`) et **abonnement** (`/abonnement`).

```bash
cp .env.example .env     # VITE_API_URL=http://localhost:8000/api
npm install
npm run dev              # développement
npm run build            # production (dist/)
```

Connexion : code entreprise + identifiant + mot de passe. Voir le [README principal](../README.md).
