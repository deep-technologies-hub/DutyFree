# Duty Free Manager — Stock

Gestion du stock : produits, catégories, fournisseurs, commandes fournisseurs (PDF, envoi email, réception), mouvements, inventaire, sommiers douaniers et alertes de rupture en temps réel.

```bash
cp .env.example .env     # VITE_API_URL=http://localhost:8000/api
npm install
npm run dev
npm run build
```

Connexion : code entreprise + identifiant + mot de passe. Voir le [README principal](../README.md).
